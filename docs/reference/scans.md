#### S0 — On-demand original scan crops (immediate priority; first POC delivered)

**Implemented:** `globe scan crop` prepares a source-hashed target offline by default; `--fetch` explicitly requests image regions through [Internet Archive’s official IIIF service](https://github.com/internetarchive/iiif). Pydantic validates source/text/hash/geometry boundaries. The resolver hashes immutable hOCR/page-map files and streams to the requested page. Full paragraphs yield padded/clamped boxes; raw Unicode spans yield separate per-line word-box crops. Word mapping requires exact reconstruction from nonblank word/line text, otherwise it fails. Spans require CLI `--expected` matching the raw selection. Corrected/normalized-text offsets are not interchangeable; reverse-mapping through correction ledgers remains future work.

The fetcher verifies official HTTPS host, explicit item/JP2 leaf identity, exact OCR/image dimensions, returned crop dimensions, and cached hashes/target/regions. It does not guess rotation/scaling or substitute another page. Downloads have45second timeouts,2MB metadata/8MB image caps, at most8regions per explicit call, no automatic retries, atomic file publication, per-output fetch locks, and `events.jsonl` request/cache/failure receipts. Compatible repeats reuse verified cache; changed targets/source hashes/configuration need new output paths. Bundles retain requested/resolved URLs, time/bytes, source and code hashes. Cache is per bundle: separate targets on one page may repeat its small metadata request.
